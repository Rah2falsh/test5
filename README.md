# 📱 Digital Menu

A dynamic and interactive digital menu application built with React as a final project for the React program at Tuwaiq Academy.

## 🚀 About the Project

Digital Menu is a responsive web app that allows users to browse menu items in an interactive and user-friendly experience. It focuses on dynamic rendering, component-based architecture, and smooth UI interactions using React.

## ⚙️ Built With

- React.js  
- JavaScript (ES6+)  
- HTML & CSS  

## 🎯 Goal

To build a modern, dynamic, and interactive menu system using React fundamentals learned during the Tuwaiq Academy React program.

## 💡 Features

- Dynamic menu rendering  
- Clean and responsive UI  
- Component-based structure  
- Interactive user experience  

## 📌 Status

Final Project – Tuwaiq Academy React Program
